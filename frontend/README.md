# Frontend Directory

This directory is reserved for the frontend application.

## Recommended Stack
- **Framework**: Vue 3 + Vite or React + Vite
- **UI Library**: TailwindCSS + Shadcn/ui or Element Plus
- **State Management**: Pinia (Vue) or Zustand (React)

## Integration
The backend API is available at `http://localhost:8000`.
CORS is already configured in `main.py` to allow requests from any origin (development mode).
